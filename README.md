# virtual-reality-msc
This project implements an Augmented Reality (AR) application built with Unity AR Foundation. The primary goal is to interactively place, scale, and interact with virtual objects through a mobile device, showcasing AR capabilities such as cloud anchors, image tracking, depth sensing, face detection, and semantic segmentation.
